# Genealogy Graph media

GIFs and screenshots of the [Genealogy Graph](https://github.com/vladushked/genealogy-graph) Obsidian plugin, kept apart so the plugin's repository stays light. The plugin's README and guides show them by their raw URLs.

- `readme/` — the README GIF and the screenshots, recorded by `npm run media` in the plugin.
- `guides/` — the GIFs of the guides (`docs/guides` in the plugin), recorded by `npm run media:guides`.

Both commands write into a clone of this repository next to the plugin's (`../genealogy-graph-media`, or `MEDIA_DIR`). Everything is recorded from fictional families; the history here is not kept, re-recorded files may replace it.
